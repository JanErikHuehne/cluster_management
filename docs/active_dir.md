# Active Directory Installation

Each compute machine needs a prefix. Lets say you want to call your computer
`myawesomecomputer`, then we need to add a prefix in our case the prefix is `TUWZC1N-`.
Active directly has limited set of characters per compute name so in this case its 15 total, 
so 7 for the actual name after the prefix. Here this would result in `TUWZC1N-myawseo`. This entry
now needs to be added to the active directory. 

For this you will need an admin access account and then follow the steps descripted [here](https://collab.dvb.bayern/pages/releaseview.action?pageId=4430492#id-11MWNADSSchnelleinstieg-Windows).
